# Contributing

Discuss bugs and small changes through the repository's Issues and pull
requests once published. Include macOS version, MacShot version, capture mode,
delay setting, reproduction steps, and expected/actual behavior. Remove client
names, screenshots, recordings, tokens, and other private information.

Keep the companion lightweight and native. Preserve existing saved preference
keys unless a migration is supplied. Never restore the ribbon into a live
scroll capture or video. Do not add paid dependencies, network tracking,
keystroke injection, or new permissions without explaining the need.

Run bash -n build.command, build on macOS, and use docs/VALIDATION.md.
Changes to upstream URL commands or window levels must be checked against
the target MacShot source/version. Do not copy GPL code into this project
under the project's custom license.

Submit original work or appropriately licensed contributions. Contributions
are provided under the project's current LICENSE; contributing does not
transfer copyright. Request changes to contributor-owned licensing separately.
